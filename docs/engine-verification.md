## 目标与证据

| 目标 | 实现与验证 |
| --- | --- |
| 用自己的数据驱动原渲染规则 | `ReadingContent.compile()` 接受 reading-set.v1；新编 community-garden 示例从文件导入，渲染 5 题 |

| 不依赖原题库 | 默认入口不包含原题库；测试在没有 data/、reference/ 的临时目录构建，输出与正常构建逐字节相同 |

| 正确判分 | 自编题全部正确得到 5/5；全部错误得到 0；大小写与首尾空白按原规则归一化 |
| 自有解析与译文 | 浏览器交卷后显示新编中文解释、标题和段落译文；原文与译文有 6 个联动片段 |
| 自有证据定位 | 根据题目内 blockId、quote 和可选 startOffset 生成定位；浏览器显示 Q1–Q5 标记及对应高亮 |
| 内容与记录隔离 | 相同输入生成稳定 ID；修改文章生成新 ID；编译不修改调用者输入 |
| 导入失败保护 | 非法 JSON 题型触发字段错误，现有题目保持可用，仍能导出 |
| 浏览器保存 | IndexedDB 保存导入源题目；刷新页面后恢复；再次打开题目恢复已提交的 5/5 复盘 |
| 单文件离线导出 | 使用页面导出按钮下载 HTML；在独立 file:// 浏览器会话中设置 offline=true，重新加载并完成 5 道题，得到 5/5，译文联动正常 |
| 返回交互 | 内嵌复盘中的“返回题目”返回导入页；单独 HTML 中显示“查看成绩” |
